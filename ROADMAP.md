# Feature suggestions

Saved from the project discussion on 2026-11-04 as the backlog for future planning.

1. **Term dates and holiday ranges** — optional activity start/end dates and
   pausing school across a holiday range. Implemented: an inclusive optional
   end date for repeating activities. Start dates and holiday ranges remain.
2. **Per-activity reminders** — different advance notice per activity and an
   optional pickup reminder.
3. **Move one occurrence to another date** — reschedule a single lesson without
   changing the weekly pattern. Current exceptions support times/cancellation.
4. **Share one occurrence** — export one dated instance of a repeating activity.
   Current activity sharing exports the series.
5. **Packing checklists** — activity-specific lists such as swimsuit, towel and
   goggles, visible with the activity.
6. **Caregiver coordination** — separate drop-off/pickup assignments, shared
   arrangements and, in a later phase, live synchronization.
